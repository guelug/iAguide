## Skill when instructions suffice

Skill = instructions + shell + existing tools. Tool = Python, keys, streaming, binaries.

Bundled in skills/; optional-skills/ via hermes skills browse; niche via hub install.

Frontmatter: platforms, requires_toolsets/tools, fallback_for_*, required_environment_variables, optional blueprint schedule.

skill_view loads body on demand. Secrets stay in .env — never shown to the model. Blueprints become suggested cron via /suggestions — install never auto-schedules.

## Compare vs OpenClaw

OpenClaw lists available_skills with a file path; the model reads SKILL.md. Hermes uses skill_view + hub trust levels.

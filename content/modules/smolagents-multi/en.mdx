## Particularity — nested smolagents

A manager plus workers is still ReAct. Each worker is a nested loop with a narrower tool list and its own memory. Isolation is the point: the parent sees a summary, not forty search snippets. Cost is another prefill.

Retrieval agents in this library are RAG as a tool (vector store, web search, fallbacks) rather than a mandatory retrieve-then-read. Vision agents take images at `run(...)` or stash screenshots on `ActionStep` via a callback. Browser agents add Helium/Selenium tools (`go_back`, `close_popups`, ctrl-F).

Sketch a manager that owns plotting and a worker that only browses. Give the worker `max_steps` smaller than the manager. If the worker can screenshot, drop images older than two steps or the window becomes a flipbook.

## Case — Sightline’s screenshot forever

Sightline’s vision greeter compared a door camera to Wikipedia. The callback saved every browser screenshot and never cleared `observations_images`. After a cookie modal, the agent “looked” until `max_steps`. They thought they needed a bigger VLM. They needed `close_popups` and a two-step image retention policy.

## Native plugin contract

plugin.yaml + register(ctx). ctx.register_tool, register_hook, register_cli_command, register_command, dispatch_tool, get_config, ctx.state.

Discovery: ~/.hermes/plugins/, project .hermes/plugins/, pip. Opt-in via hermes plugins enable. Doctor checks manifests.

tools.override needs capabilities plus allow_tool_override. Handlers return JSON strings.

Specialized kinds: model-provider, platform, memory, context_engine.

## Compare vs OpenClaw

OpenClaw installs plugins on the Gateway. Hermes loads them in-process.

**Case.** Two plugins claim the same tool.

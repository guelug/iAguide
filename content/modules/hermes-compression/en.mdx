## Dual system

Gateway session hygiene at 85% of context (rough tokens, history >= 4) is a safety net for overnight chats. Agent ContextCompressor at 50% uses real API tokens. Same 50% on both caused premature compress every gateway turn.

Four phases: (1) prune old tool results >200 chars, (2) boundaries -- protect_first_n, summarised middle, tail by token budget or protect_last_n=20, (3) structured summary via auxiliary LLM, (4) reassemble + sanitize tool pairs.

Default compression.in_place: true -- same session id, old turns soft-archived (active=0, compacted=1), still searchable. in_place: false restores parent_session_id lineage.

Anthropic **system_and_3**: breakpoint 1 = system prompt; 2-4 = last three non-system messages. TTL 5m or 1h. Model identity is part of the cache key -- /model, fallback, credential pool rotation = zero hits.

## Compare vs OpenClaw

OpenClaw safeguard compaction can refuse to write a bad summary. Hermes 4-phase pipeline plus in-place was built to kill rotation bugs (lost /goal, orphaned sessions).

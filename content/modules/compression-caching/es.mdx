## Dos trabajos que se mezclan

**Compactacion** reduce lo que *ve el modelo*: resume el medio, conserva cola verbatim, no parte pares tool_call/resultado.

**Cache de prefijo** reutiliza *computo* si el prefijo es identico byte a byte. Los breakpoints clavan el system prompt y una ventana rodante.

Tras compactar, la region comprimida falla cache; el system prompt puede sobrevivir.

## Umbrales dobles

Una higiene de **gateway** alta (Hermes 85%) caza el Telegram nocturno. Un compresor **en el bucle** mas bajo (50%) es el gestor normal. OpenClaw compacta cerca del limite o ante overflow y puede volcar memoria antes.

## Two extension knobs

**Plugin** - code with a manifest. Registers tools, hooks, CLI subcommands, slash commands, platforms, providers.

**Skill** - SKILL.md (frontmatter + procedure). Loaded on demand. Prefer a skill when existing tools plus shell are enough.

## Case: two plugins, one tool name

**Case.** Two plugins both register web_search. Without an override gate, last-load wins or the registry rejects the shadow.

**Practice.** Unique names; explicit override plus consent; log the winner.

## A turn is a trace

Without observability, an agent is a black box that sometimes emails the customer. **Traces** are one user task end-to-end. **Spans** are the steps inside: prefill, decode, tool call, subagent, retrieve. OpenTelemetry is the usual wire; Langfuse, Arize, Phoenix are dashboards that speak it. smolagents can instrument with `SmolagentsInstrumentor`.

Watch: latency (task and step), cost (tokens and tool APIs), request errors, explicit feedback (👍), implicit feedback (same question twice), accuracy labels you define, and automated judges (RAGAS for RAG, a guard for injection). Offline eval on a fixed set first; online monitoring after deploy; feed new failures back into the offline set.

## Case — SignalOps’ calm latency

SignalOps’ p95 was 1.8s — green on the dashboard. Tool error rate was 40% (timeout to the CRM). The model apologised quickly, so latency looked fine. They alerted on p95 alone. A span error ratio would have paged them on day one.

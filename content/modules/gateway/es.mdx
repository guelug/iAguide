## Un proceso, muchas superficies

Un **gateway** es el dueño longevo de las plataformas de chat. Los clientes no abren cada uno su sesión de WhatsApp.

Patrón: plataforma → adaptador → evento → autorizar → clave de sesión → run → entregar.

<VisualSlot caption="Los adaptadores normalizan; auth y pairing abren la puerta; la entrega sale." />

## Trabajos del gateway

Adaptadores, pairing/allowlists, slash commands con guarda, entrega (a menudo sin espejo en el transcript), fondo (cron, caducidad, flush de memoria).

## Hermes frente a OpenClaw

Hermes: `GatewayRunner`, clave `agent:main:…`, guarda de dos niveles, `/pair`. OpenClaw: un Gateway por host en WebSocket `:18789`, protocolo tipado, nodes `role: node`, Tailscale Serve.

## Caso: dos perfiles, un token

**Caso.** Dos procesos comparten el mismo token de Telegram. Uno muere o ambos aletean.

**Patrón.** Bloqueo por token / un solo dueño de la sesión del bot.

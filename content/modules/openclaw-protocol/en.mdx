## Frames, not ad-hoc JSON

Transport: WebSocket text frames. First frame MUST be connect. Non-JSON or non-connect first frame is a hard close.

After handshake: {type:req, id, method, params} -> {type:res, id, ok, payload|error}. Events: {type:event, event, payload, seq?}. TypeBox schemas generate JSON Schema and Swift models.

All connects sign connect.challenge. Signature payload v3 also binds platform and deviceFamily. Side-effecting methods (send, agent) require idempotency keys. Events are not replayed.

## Compare vs Hermes

Hermes has no public WS control plane; adapters emit MessageEvent in-process. OpenClaw protocol is the contract for every client and node.

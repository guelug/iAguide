## Files that are the persona

Workspace cwd is the only working directory. Injected: AGENTS.md (ops), SOUL.md (voice), IDENTITY.md (name/vibe), USER.md (who you are), BOOTSTRAP.md (first-run ritual, deleted after), MEMORY.md if present.

Daily files memory/YYYY-MM-DD.md are NOT in normal Project Context — memory_search / memory_get on demand. Bare /new can prepend recent dailies once.

Truncation: 20k per file, 60k total. Sub-agents only get AGENTS.md. SOUL.md is voice, not a security policy — keep rules in AGENTS.md.

## Compare vs Hermes

Same pattern (SOUL/AGENTS/MEMORY/USER). OpenClaw adds IDENTITY + BOOTSTRAP and date-stamped daily files as the memory grain.

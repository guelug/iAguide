## Particularity — when the loop is a graph

LangGraph encodes the general cycle as a **compiled state machine**. Use it when control flow is the product: branch on class, join parallel work, wait for a human, persist state. Do not use it because a blog post said “graphs.”

Building blocks:

- **State** — a typed dict (or reducer-backed fields) that every node reads and patches.
- **Nodes** — Python functions: LLM call, tool, condition, human.
- **Edges** — always-next, or conditional on state.
- **Reducers** — how two writes to the same field merge (append messages, overwrite a flag).
- **START / END** — the only honest exits.

## Case — Reviewly’s cycle with no exit

Reviewly’s document graph sent “needs more evidence” back to retrieve with no hop counter. One PDF with empty embeddings looped until the bill hurt. They added an `attempts` field and an edge to END when `attempts > 2`. The graph was fine. The missing reducer on `attempts` was the incident.

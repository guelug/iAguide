## Tools vs skills vs plugins

Tools are typed functions. Skills are SKILL.md packs. Plugins add tools from ClawHub.

group:runtime, group:fs, group:web, group:ui. Policy filters what the model sees. Coding profile has web_search but not browser.

Hermes uses named toolsets. OpenClaw uses groups plus allow/deny plus a sandbox tool gate.

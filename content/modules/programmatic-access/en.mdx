## Same loop, four sockets

| Surface | Transport | Best for |
| --- | --- | --- |
| ACP | JSON-RPC over stdio | VS Code, Zed, JetBrains that already speak Agent Client Protocol |
| HTTP API | OpenAI-shaped /v1/chat/completions + SSE | curl, Open WebUI, CI |
| TUI / Gateway WS | JSON-RPC (Hermes TUI gateway; OpenClaw :18789) | custom hosts that need slash commands, approvals, steer |
| In-process | import AIAgent / embedded runtime | Python embed without a subprocess |

If the IDE already speaks ACP, do not invent a second HTTP dialect.

Hermes: hermes acp, api_server, tui_gateway, run_agent.AIAgent. OpenClaw: Gateway WS is the control plane; ACP and HTTP sit on top.

## Case: chat_completions for an ACP IDE

**Case.** A VS Code plugin posts OpenAI chat completions to a local API server, then tries to render tool diffs by parsing streamed text. Permissions and cancel are wrong.

**Fix.** Speak ACP: sessions, permission requests, session_update, cancel.

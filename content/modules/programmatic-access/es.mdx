## Mismo bucle, cuatro sockets

ACP (stdio) para IDEs. HTTP OpenAI para curl y frontends. WS/JSON-RPC para hosts a medida. In-process para tests Python.

Si el IDE habla ACP, no inventes un segundo dialecto HTTP.

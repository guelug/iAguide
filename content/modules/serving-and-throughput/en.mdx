## Fast for you is not cheap for everyone

One user, one model copy, idle SMs: fine for a laptop. A server wants **continuous batching** (admit new requests mid-decode), **paged attention** / paged KV (so memory is not one giant slab per request), and sometimes **speculative decoding** (a small draft model proposes tokens; the big model verifies).

Throughput (tokens/s across users) and latency (time to first token for you) trade. vLLM, TensorRT-LLM, and friends are the usual names — read *their* current docs; flags move.

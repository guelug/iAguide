## Opaque credentials in the sandbox

iron-proxy is a MITM CONNECT proxy that swaps sandbox-facing tokens for real provider keys. The sandbox never sees OPENROUTER_API_KEY.

Default deny CIDRs: loopback, RFC1918, IMDS 169.254.169.254. CA and mappings.json 0o600. Never bind 0.0.0.0. Docker injects HTTPS_PROXY + CA when proxy.enabled.

Profiles: hermes -p name gets its own HERMES_HOME, config, memory, sessions, gateway PID, and egress mappings.

## Compare vs OpenClaw

OpenClaw splits sandbox vs tool policy vs elevated. Hermes egress is a credential-injection firewall in front of tool backends.

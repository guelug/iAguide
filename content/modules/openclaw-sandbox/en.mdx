## Three knobs, three answers

Sandbox (agents.defaults.sandbox.mode off/non-main/all) is WHERE tools run. Tool policy (allow/deny, profiles, group:runtime/fs/...) is WHICH tools exist. Elevated is exec-only: run outside the sandbox when already sandboxed — it does not grant extra tools.

deny always wins. If allow is non-empty, everything else is blocked. /exec cannot override a denied exec tool. group:runtime is exec/process/code_execution.

Debug: openclaw sandbox explain --json.

## Compare vs Hermes

Hermes: toolsets + check_fn + iron_proxy egress. OpenClaw: sandbox location vs allow/deny vs elevated, with group:* shorthands.
